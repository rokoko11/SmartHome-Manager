# SmartHome-Manager
  SmartHome Manager - это мобильное приложение, позволяющее пользователям управлять умными устройствами (освещение, розетки, климат, датчики), настраивать автоматические сценарии и получать уведомления о событиях в доме.
    Основная цель:
    Обеспечить удобное, безопасное и удалённое управление умным домом через мобильное устройство.
