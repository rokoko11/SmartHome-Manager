
# Управление версиями SmartHome Manager

## Правила работы с ветками

- main — стабильная версия проекта.
- develop — интеграция изменений.
- feature/* — разработка отдельных функций.

## Правила коммитов

Каждый коммит должен описывать конкретное изменение.

Примеры:
- Добавлена проверка названия устройства.
- Исправлена ошибка переключения состояния лампы.
- Добавлены тесты управления устройствами.

## Правила выпуска релизов

Перед выпуском проверяются автоматические тесты.
После проверки создаётся версия проекта и публикуются release notes.
